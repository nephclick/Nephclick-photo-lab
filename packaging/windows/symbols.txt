Nephclick PhotoLab debug symbols

nephclick-photolab.pdb and nephclick_photolab_cli.pdb are the debug symbols of nephclick-photolab.exe and
nephclick-photolab-cli.exe from the release with the same version and architecture as this zip. They
were written by the same build as those exes, so they match only them: a PDB from a local build
of the same commit doesn't.

They hold Nephclick PhotoLab's function names (release builds carry no source line tables), which is
what a profiler needs to show where the time goes. Nephclick PhotoLab doesn't need them to run.

To use them, either copy both files next to nephclick-photolab.exe (the installer's folder, by default
C:\Program Files\NephclickPhotoLab), or add this folder to the profiler's symbol path:

  Windows Performance Analyzer: Trace > Configure Symbol Paths, add this folder, then
                                Trace > Load Symbols.
  Superluminal:                 Settings > Symbols, add this folder as a symbol location.
  Visual Studio:                Tools > Options > Debugging > Symbols, add this folder.
  Any tool reading _NT_SYMBOL_PATH: set _NT_SYMBOL_PATH to this folder.

When you share a profile in a Nephclick PhotoLab issue, say which version and architecture you ran
(Help > System Info).
